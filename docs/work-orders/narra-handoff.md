# Handoff — контекст работы над Narra (ReadAny)

Файл для продолжения работы с любого компьютера / новой сессией ассистента.
Прочитай его целиком, затем `narra-core-loop.md` (work order) и
`narra-core-loop-ledger.md` (журнал фаз P1–P15) в этой же папке.

## Состояние на 11.08.2026

- **Основной репозиторий**: github.com/mishanaer/ReadAny (Expo-приложение
  в `packages/app-expo`). Десктопный прототип narra (Electron) — отдельный
  репозиторий sboo-create/narra, использовался как референс UX и промптов.
- **Влито в main**: вся кампания P1–P15 (fanart-стиль, правила голосов,
  таббар, кликабельные имена, озвучка по ролям с ударениями, панель
  Apple Books, импорт с Фикбука и пр.) + редизайн команды (типографские
  обложки, новый таббар Библиотека·Чаты·Профиль).
- **Открытый PR: #15 «Сцены»** (ветка `feat/scene-generation`), ждёт ревью
  Миши. Внутри: генерация сцен через OpenRouter (жанровые промпты из 5
  блоков, действие вместо статики), врезки «Показать сцену» ВНУТРИ текста
  (первая на 1–3 стр., далее раз в 4), «Оживить» через Veo (image-to-video),
  редизайн экрана «Сцена», «стр. N из M», чистка каталога от Викитеки,
  «Одиссея» 18-й книгой каталога. Миша уже коммитил в эту ветку
  (фикс гонки генерации) — ветка совместная.

## Ключи и окружение

- `packages/app-expo/.env.development` — НЕ в гите. Нужны строки:
  `EXPO_PUBLIC_NARRA_GATEWAY_URL`, `EXPO_PUBLIC_NARRA_GATEWAY_AUTH_MODE`
  (см. NARRA_GATEWAY.md) и `EXPO_PUBLIC_OPENROUTER_API_KEY` (ключ у Миши;
  по нему клиент генерит обложки, сцены и видео-оживление).
- Гейтвей: api.narra.disrupt.builders (`/v2/*`). Голос Фокина `Efo` на нём
  отдаёт 400/502 — исключён из автоназначения до починки.

## Как запускать локально (симулятор)

1. `corepack pnpm install` в корне; `cd packages/app-expo`.
2. Дев-сервер: `corepack pnpm exec expo start --dev-client` (LAN, без
   туннелей — правило AGENTS.md).
3. Нативная сборка: `corepack pnpm exec expo run:ios` (первый раз долго).
   На Xcode 26.6 патч `patches/react-native-screens@4.25.2.patch` не
   компилируется (в SDK нет UITab.selectedImage) — локально откатить патч
   в node_modules; на EAS-сборки не влияет.
4. Врезки диагностируются логами `[SceneSlot]` в Metro.

## Правила работы (важное из фидбека Сони)

- Всё новое в UI — ТОЛЬКО нативные элементы, шрифты SB Sans / SB Serif,
  дизайн-система deslop-primitives, никаких самодельных аналогов.
- Референс UX — десктопная narra (карточка героя, врезки сцен, панель).
- Стиль генераций — полуреалистичное аниме/фанарт, строго без букв.
- Врезки сцен: картинка в тексте, не отдельным экраном; лоадер — контурный
  логотип цветом темы.
- Коммиты — русские, по AGENTS.md; секреты в git не класть.
